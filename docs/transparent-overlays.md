# BiliCast 透明悬浮组件

## 1. 模块边界

本版包含两个独立 Tauri Webview 窗口：

- `danmaku-overlay`：全屏透明、置顶、默认鼠标穿透；接收到事件后按轨道从右向左滚动。
- `event-sidebar`：纯透明侧边事件流、置顶、可放在屏幕左侧或右侧；没有事件时不绘制任何可见背景，收到事件后才显示独立气泡。

两个窗口各自订阅统一的 `live://event` 领域事件，彼此不引用组件状态。主窗口只负责保存设置、开关窗口与发送预览事件。设置通过 `overlay://settings` 广播，预览通过 `overlay://preview` 广播。

```text
Web Live Adapter ── live://event ──┬── 全屏滚动弹幕窗口
                                   └── 侧边事件窗口

主窗口参数面板 ─ overlay://settings ──> 两个独立窗口
主窗口预览按钮 ─ overlay://preview  ──> 两个独立窗口
```

## 2. 全屏滚动弹幕参数

- 事件类型：弹幕、互动、礼物、SC、大航海、系统；
- 昵称、头像与鼠标穿透开关；
- 每一种事件的独立颜色；
- 字体族、字号、粗细、整体不透明度；
- 描边颜色、描边宽度、阴影颜色、阴影模糊；
- 按像素/秒控制速度，或按总时长控制整段运动；
- 滑入时间、滑出时间；
- 垂直显示起点/终点、轨道间距、最大同屏条数。

事件到来时会选择下一个可用轨道，并使用 Web Animations API 完成位移和透明度动画。窗口本身不拦截鼠标时，直播软件与游戏仍可正常接收点击。

## 3. 侧边事件栏参数

- 事件类型过滤；
- 左/右停靠、窗口宽度与高度；
- 头像、UID、鼠标穿透开关；
- 每一种事件的强调色；
- 字体族、字号、粗细、文字色；
- 气泡底色、气泡透明度、玻璃模糊和小圆角；窗口与消息列表外壳始终保持纯透明；
- 最大保留事件数、单条停留时间、滑入时间、滑出时间与滑动距离。

默认气泡采用 8px 小圆角、细事件强调条、方圆头像框和轻量玻璃阴影。进入动画包含侧向滑入、轻微回弹和去模糊，退出动画包含侧向位移、上浮与淡隐；系统启用“减少动态效果”时动画时长自动归零。

点击穿透关闭时，可拖动透明区域调整窗口；参数页仍可随时调整位置、尺寸或关闭窗口。滑动速度由滑动距离与滑入/滑出时间共同决定。

## 4. 使用流程

1. 先在 **连接设置** 登录并在 **播报台** 连接直播间。
2. 进入 **悬浮组件**，分别配置全屏弹幕和侧边事件栏。
3. 点击 **打开并预览**，BiliCast 会创建真实透明窗口并注入一组样例事件。
4. 用主窗口中的参数继续调整；设置会自动保存并实时同步到已打开窗口。
5. 开播时建议开启鼠标穿透；结束后在参数页点击关闭对应窗口。

设置保存在主窗口的 `localStorage`，模型与直播连接逻辑不依赖悬浮层。后续新增 OBS 浏览器源或主题预设时，可继续复用同一组领域事件和设置类型。
